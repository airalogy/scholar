# 管理控制台

Scholar 在同一个产品中提供分层管理控制台。账号登录后，系统会从服务器获取当前权限，只显示已授权的工具和机构。

## 管理层级

### 平台控制台

平台管理员可以处理全局学科目录、用户反馈、跨机构审核队列及各机构的管理入口。

### 机构控制台

机构 owner 和 admin 可以管理机构内容、成员权限、学科映射、实验室和审核工作。普通 member 只会获得被单独授予的能力：

- `can_review_content`：处理所属机构的内容审核。
- `can_import_data`：向所属机构导入论文和学者数据。

这两项权限相互独立，也不会自动授予成员管理或系统凭证管理权限。

## 访问与安全

浏览器中的菜单和路由检查用于提供清晰的使用体验；真正的权限边界仍由每个服务器 API 独立校验。账号无权访问某项功能时，系统会显示权限受限页，不会展示其他机构的管理数据。
