# Airalogy Scholar Repository Documentation

English | [简体中文](../zh/README.md)

These documents are for maintainers, contributors, release engineers, and operators of the Airalogy Scholar source repository. They cover architecture, governance rules, private deployment, and release procedures.

Product users, institution administrators, and system integrators should use the versioned documentation in [`apps/docs`](../../apps/docs/), which is bundled with each Web image at `/docs/en/` and `/docs/zh/`. Repository-maintainer runbooks are intentionally not published in that product documentation site.
